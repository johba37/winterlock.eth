Networks · Base

Use Ridgeline Grants on Base

Your treasury has the same address on every network, and 1,200 USDC is already waiting on Base. The team's first payment there sets the account up.

What happens

  1. Each approving member's signer makes a fresh key set for Base4,096 queue positions, about 10 seconds on a laptop
  2. Their main keys sign an introduction for itValid only for this account, on Base, for that member
  3. The first payment carries the introductionsIt deploys the account and stores the key sets. Later payments cost the normal amount.
In technical terms

One key of the member's master tree signs a certificate that binds a per-chain WOTS+ key tree to chain 8453, the validator, this account and the member (decision D10). The validator stores the tree on the first operation that carries it, about 190k gas per member.
